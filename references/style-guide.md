# 图像风格指南

## 概述

本文档提供丰富的图像风格关键词库，帮助用户快速构建高质量的 Prompt。风格关键词是 Prompt 的核心组成部分，直接影响生成图片的视觉效果。

## 风格组合公式（实战模板）

```
[主体描述] + [风格] + [光线] + [构图] + [画质] + [比例/尺寸]
```

**示例：**

```
a cute cat sitting on a windowsill,
flat illustration style, corporate memphis,
soft ambient light, centered composition,
vector art, clean lines,
8k ultra-detailed
```

## 风格避坑指南

### 常见风格冲突

| 冲突组合 | 问题 | 解决方案 |
|---------|------|---------|
| 写实 + 卡通 | 风格混乱 | 选择一种主导风格 |
| 极简 + 复杂细节 | 矛盾 | 明确主次关系 |
| 暖色调 + 冷色调 | 色彩冲突 | 统一色调方向 |
| 复古 + 未来 | 时代冲突 | 选择一个时间线 |

### 风格词过多的问题

**❌ 错误示例**：
```
A cat, photorealistic, cartoon style, watercolor,
oil painting, digital art, minimalist, detailed,
vintage, modern, futuristic, retro
```

**✅ 正确示例**：
```
A cute cat,
flat illustration style,
pastel colors,
clean background,
modern design
```

**原则**：每次只定 1-2 个主风格，避免风格词过多导致模型困惑。

## 风格库管理建议

### 建立个人风格库

1. **收集优秀案例**：看到好的图片，记录其风格关键词
2. **分类整理**：按用途、风格、场景分类
3. **标注效果**：记录哪些风格词组合效果好
4. **持续更新**：随项目积累不断丰富

### 风格种子 Prompt

为常用场景建立"风格种子 Prompt"，确保风格统一：

```markdown
## 科技风格种子

```
[主体], tech illustration, blue gradient,
futuristic UI elements, clean lines,
modern design, professional quality
```

## 国风风格种子

```
[场景], Chinese ink painting style,
shuimo brushwork, muted earthy tones,
traditional composition, red seal stamp
```
```

## 总结

- **风格是 Prompt 的灵魂**：选对风格，事半功倍
- **少即是多**：1-2 个主风格词足够，不要堆砌
- **参考优秀案例**：站在巨人肩膀上
- **建立风格库**：积累复用，保持一致性
- **按需选择**：不同场景用不同风格

**一句话：风格要具体、要统一、要适合场景。**
